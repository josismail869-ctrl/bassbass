# Probashi Voice — Global Portal

This package contains the responsive Probashi Voice portal recreated from the supplied reference artwork.

## Files

- `index.html` — main page
- `styles.css` — responsive visual system
- `script.js` — navigation, room buttons, menu, and search interactions
- `assets/ProbashiVoiceGlobalPortal.png` — supplied visual reference asset
- `server.js` — lightweight local static server
- `package.json` — start script
- `public/manus-routes.json` — route manifest

## Run locally

```bash
npm start
```

Then open `http://localhost:3000`.

The page includes responsive desktop/mobile layouts, all eight country rooms, search feedback states, and official YouTube, WhatsApp, X, Threads, and Email links.
